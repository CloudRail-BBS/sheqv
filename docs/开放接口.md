# 资源库开放接口

给外部站点、导航站、桌面小工具用的只读接口。不需要登录，带 CORS，可以直接在浏览器里 `fetch`。

基地址：`https://crbbsx.com`。所有接口都只返回**已发布**资源，下架与待审一律 404。

## 1. 列表

```http
GET /api/v1/public/resources?game=minecraft&source=modrinth&sort=downloads&limit=20&offset=0
```

| 参数 | 说明 |
| --- | --- |
| `game` | `minecraft` / `rusted_warfare`，留空为全部 |
| `category` | 分类 key（见 `/api/v1/public/meta`） |
| `source` | 来源站：`curseforge` / `modrinth` / `rtsbox`，留空为全部（含本站资源） |
| `q` | 关键词，匹配标题、简介与标签 |
| `sort` | `new`（默认）/ `old` / `likes` / `downloads` |
| `limit` | 每页条数，1–100，默认 20 |
| `offset` | 偏移，默认 0 |

## 2. 详情

```http
GET /api/v1/public/resources/{id}
```

比列表多 `body`（Markdown 正文）与 `files`（附件列表）。附件下载地址形如
`/api/v1/resource-files/{fileId}`，需要登录态时由调用方自行处理。

## 3. 字典

```http
GET /api/v1/public/meta
```

返回 `games`（含每个游戏支持的来源站）、`sources`、`sourceKinds`、`categories`、`sort`。
接入方不要把这些枚举写死在自己代码里。

## 4. 约定

- **限流**：与站点共用，单 IP 建议不超过 1 次/秒；`Cache-Control: public, max-age=60`，可以放心缓存一分钟。
- **来源站**：`source` 非空时，`url` 指向来源站条目；`sourceId` 是该项目在该站的标识。
  拼接规则在服务端与前端各有一份（`resources::source_url()` / `sourceUrlFor()`），改一处要同步另一处。
- **不要抓 `/api/v1/resources`**：那是站内接口，依赖 Cookie，字段随时可能为前端调整而变。

## 5. 示例

```bash
# 最近上架的 10 个 Minecraft 资源
curl 'https://crbbsx.com/api/v1/public/resources?game=minecraft&limit=10'

# 只看 Modrinth 的模组，按下载量排
curl 'https://crbbsx.com/api/v1/public/resources?source=modrinth&sort=downloads'

# 铁锈战争来自 rtsbox 的条目
curl 'https://crbbsx.com/api/v1/public/resources?game=rusted_warfare&source=rtsbox'
```
